# Real-Time Multi-Client Communication System

A socket-based real-time communication platform developed using Python that supports multiple concurrent users through TCP socket programming and multi-threaded server architecture.

## Features

* Multi-client support
* Group messaging
* Private messaging
* Online users list
* Chat logging
* Tkinter GUI
* Multi-threaded communication

## Technologies Used

* Python
* Socket Programming
* Threading
* TCP/IP
* Tkinter

## How to Run

### Start Server

```bash
python server/server.py
```

### Start Client

```bash
python client/client.py
```

Open multiple clients to simulate real-time communication.

## Concepts Demonstrated

* TCP Socket Programming
* Client-Server Architecture
* Multi-threading
* Concurrent Connections
* Synchronization using threading.Lock
* Real-Time Communication Systems
